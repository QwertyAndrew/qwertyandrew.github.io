    Animating

    I animate humanoid before in Roblox Studio, but I never animate a quadruple before, nor animate using controls. It is best to get some references.

    This is a wolf, so how does a dog/wolf run?

    Based on this video on how to animate an animal run cycle, I learned that there are 5-6 main stage of the animation.

    Contact, or Extension: Front legs stretched forward, back legs stretched backward. Body is fully extended.
    Going down: The front legs begin absorbing impact. Spine compresses slightly downward.
    Passing: Back legs move under the body. Front legs pull backward. Body starts lifting again.
    Full contraction: All legs tucked closer beneath the body. Apparently this is the “coiled spring” pose, the back legs about to touch the ground.
    Leap: The wolf fully off the ground. Spine extends again. Front legs reaching forward/backward, while the back legs pushing up.
